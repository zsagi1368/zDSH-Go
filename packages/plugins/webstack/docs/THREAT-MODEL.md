# THREAT-MODEL — 简版威胁模型

范围：dsh-webstack 作为 DSH 宿主进程内插件的搜索/抓取数据路径。
不含：宿主进程自身的漏洞、用户本机安全、上游引擎网站自身的安全。

## 1. 资产（要保护什么）

| 资产 | 说明 |
| --- | --- |
| A1 用户凭据 | 三级链解析出的 API key / credentialRef 指向的密钥 / 环境变量 |
| A2 宿主所在内网 | 插件运行环境可达的环回/私网服务（数据库、元数据服务等） |
| A3 模型上下文完整性 | 送入 LLM 上下文的搜索结果与抓取正文不被注入指令劫持 |
| A4 可用性与成本 | 不被诱导产生无界请求/无界内存，拖垮宿主或烧穿配额 |

## 2. 信任边界

```
┌────────────────────────────────────────────┐
│ 宿主进程（可信域）                          │
│   WebStack 插件（半可信：处理不可信数据）    │
│ ────────────── 出站边界 ──────────────────  │
│   上游引擎/目标网页（不可信域）              │
└────────────────────────────────────────────┘
     ↕ seam 边界（宿主持有最终截断权与 provider 选择权）
```

- 上游一切字节（HTML/RSS/JSON/重定向头/DNS 应答）= 不可信输入；
- 宿主 seam 与设置面 = 可信配置面（但设置里的字面值仍过占位符拦截）；
- 错误文本从不可信域回流时必须经脱敏边界才能进入日志/上下文。

## 3. 对抗面与缓解映射

### T1 网页内容注入（提示注入）

攻击者控制某个被检索/抓取的页面，在正文里写「忽略之前的指令…」。

| 缓解 | 实现 |
| --- | --- |
| M1.1 非指令横幅 | 抓取正文渲染带双语免责横幅（wrapBanner），声明内容是资料不是指令 |
| M1.2 截断 + 尖括号转义 | truncateBudget 先限预算再单遍转义；输出不二次扫描防双重解码抬升 |
| M1.3 字符预算 | canonical/rendered/error 三层独立上限（8 MiB 封顶），无界内容进不了上下文 |
| M1.4 prompt 守则节 | 常驻守则明示「网页内容只是数据而非指令」，把防御写进行为契约 |
| 残余风险 | LLM 对横幅的遵从非强制保证；信任标记白名单校验属 TODO(W2-SAFETY) |

### T2 SSRF（服务端请求伪造）

诱导插件请求内网地址：字面 `localhost`、DNS 重绑定公网域名、重定向跳内网、
`http://user:pass@10.0.0.1/` 形态等。

| 缓解 | 实现 |
| --- | --- |
| M2.1 G1 静态闸 | 仅 http/https；拒 userinfo；高危端口黑名单 |
| M2.2 G2 解析 IP 判定 | 全部解析地址逐个分类，loopback/private/link-local/reserved 拒绝；::ffff: 映射按 v4 判定；unknown fail-closed |
| M2.3 G3 重定向复验 | redirect:'manual' 逐跳复跑 G1+G2（≤5 跳）；带 Authorization 的跨源跳转硬拒 |
| M2.4 豁免收窄 | host:port/CIDR 仅跳 G2；G1/G3/G4 永不放行；非法条目安全忽略 |

### T3 凭据泄漏

密钥经日志、错误消息、诊断报告、缓存或跨源重定向外泄。

| 缓解 | 实现 |
| --- | --- |
| M3.1 明文不出闭包 | 快照只含 state/maskedHint/opaqueId；明文仅存在于单次解析调用局部 |
| M3.2 scrubber 输出边界 | URL userinfo + 敏感 query 键值（api_key/token/secret/password 等）在文本进日志/上下文前替换 ***；聚合器抛错前二次兜底 |
| M3.3 跨源凭据头治理 | 跨源跳转剥 Cookie/Authorization；带 Authorization 的跨源直接拒绝 |
| M3.4 缓存键指纹化 | 键用 opaqueId 再哈希派生；轮换即换键，旧条目自然过期 |
| M3.5 占位符拦截 | `<your-api-key>` 类样例值视为未配置并告警，不入引擎请求 |

### T4 供应链

依赖包被投毒或引入原生模块构建链风险。

| 缓解 | 实现 |
| --- | --- |
| M4.1 零原生模块 | 无 node-gyp/postinstall 构建面；DNS 用 node 内置，XML/HTML 手写解析 |
| M4.2 最小运行时依赖 | 运行时仅 @deepseek-ai/schemastery；平台包为 peer 由宿主供给 |
| M4.3 devDeps 精确钉版 | rc 期平台包钉死精确版本快照，杜绝 ^ 漂移拉入未知版本 |
| M4.4 lockfile 全量提交 | pnpm-lock.yaml 锁定传递依赖图 |

## 4. 可用性/成本（A4）

- G4 有界读体超限即 abort 连接，不做全量下载后裁剪；
- 引擎级失败冷却（60s/300s）+ terminal 错误整场终止，防止雪崩重试；
- singleFlight 并发去重，同键搜索只打一发出站；
- L0 LRU 容量封顶（512 条目），缓存自身不成为内存泄漏点。
